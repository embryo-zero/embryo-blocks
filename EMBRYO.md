# Embryo Blocks

Embryo Blocks is Embryo-Zero's fork of [Microsoft MakeCode (PXT)](https://github.com/microsoft/pxt) (v13.3.2-1-g6a6b1e1e3, commit 6a6b1e1e3). It does block coding for kids and hardware.

- Our changes live on the `embryo` branch. The original license files (LICENSE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
